# Centre Holistique – الموقع

## النشر على GitHub Pages
1. في github.com أنشئ مستودعاً جديداً (New repository) باسم مثلاً `centre-holistique`، واجعله **Public**.
2. اضغط **Add file → Upload files** واسحب: `index.html` و `admin.html` والمجلدين `assets` و `data`، ثم **Commit changes**.
3. اذهب إلى **Settings → Pages**، وفي *Source* اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/ (root)`، واضغط **Save**.
4. بعد دقيقة أو دقيقتين يصبح الموقع متاحاً على: `https://اسم-المستخدم.github.io/centre-holistique/`

## لوحة التحكم
- الرابط: `…/admin.html`
- تحتاج رمز دخول (token) من GitHub: Settings → Developer settings → Fine-grained tokens → صلاحية **Contents: Read and write** على هذا المستودع فقط.
- منها تضيف وتعدّل الدورات والجلسات والباقات والآراء والأسئلة ورقم واتساب والصور.

## الحجوزات
- كل طلب (من السلة أو من استمارة الحجز) يصلك كرسالة على **واتساب** في الرقم المسجّل في لوحة التحكم.
