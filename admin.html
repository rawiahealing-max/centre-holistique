الدخول عبر GitHub

كل تعديل تقوم به يُحفظ مباشرة في مستودع GitHub الخاص بك، ويتحدّث الموقع تلقائياً بعد حوالي دقيقة.

كيف أحصل على الرمز (token)؟
  1. في GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens
  2. اضغط Generate new token، اختر Only select repositories ثم اختر مستودع الموقع.
  3. في Permissions → Contents اختر Read and write.
  4. انسخ الرمز والصقه هنا. لا تشاركه مع أي شخص.
